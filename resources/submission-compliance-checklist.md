# Directory Submission Compliance Checklist

Run this before submitting to each directory. Re-check the directory's own submission page because terms, prices, and eligibility can change.

## Relevance and eligibility
- [ ] Directory currently accepts submissions.
- [ ] Product is a genuine fit for its audience and category.
- [ ] Eligibility and geographic restrictions are satisfied.
- [ ] Duplicate listing does not already exist.
- [ ] Current listing requirements have been read on the directory's own site.

## Facts and assets
- [ ] Product name and canonical URL are correct.
- [ ] Description and feature claims match the live product.
- [ ] Pricing and availability are current.
- [ ] Logo and screenshots are current and approved for public use.
- [ ] Metrics, reviews, and customer claims are supported by evidence.
- [ ] Contact details have been approved for public disclosure.

## Terms and approval gates
- [ ] Free versus paid status has been verified on the directory's own site.
- [ ] No payment or paid upgrade is selected.
- [ ] No account is created without explicit approval.
- [ ] CAPTCHA or identity checks are not bypassed.
- [ ] Backlink, badge, or reciprocal-promotion requirements are escalated for approval.
- [ ] Terms, privacy policy, and data-sharing implications are reviewed when relevant.

## Recordkeeping
- [ ] Submission date and exact status are recorded.
- [ ] Confirmation URL or listing URL is saved.
- [ ] Follow-up date is set only when a real follow-up is useful.
- [ ] Rejected, paid-only, or unavailable submissions are recorded with a reason.

**Stop condition:** If the form requests payment, login, account creation, a badge/backlink, personal details not in the approved brief, or acceptance of terms, stop and ask the user before proceeding.
