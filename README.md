# claude-ai-directory-submitter-skill

A Claude Code skill for preparing and managing product listings across relevant AI, SaaS, API, software, and launch directories.

## Capabilities

- Build a verified product brief.
- Find and assess relevant listing destinations.
- Compare audience fit, requirements, effort, and cost.
- Prepare consistent listing copy and assets.
- Submit one destination at a time with approval gates.
- Track confirmations, live URLs, rejections, and follow-ups.
- Measure referral traffic and qualified signups.

## Install

~~~bash
git clone https://github.com/Brajesh31/claude-ai-directory-submitter-skill.git ~/.claude/skills/ai-directory-submitter
~~~

## Use

~~~text
/ai-directory-submitter
~~~

Provide the product website, target users, value proposition, pricing, approved assets, and submission restrictions. Review the product brief before any listing is submitted.

## Workflow

1. Prepare and approve the product brief.
2. Identify candidate destinations.
3. Verify current requirements and costs.
4. Prioritize by audience fit and likely value.
5. Prepare each listing using approved information.
6. Obtain approval for gated or consequential steps.
7. Record the exact submission result.
8. Check live status and evaluate performance.

## Operating principle

A small number of relevant listings is usually more valuable than hundreds of low-fit submissions. Measure real outcomes rather than counting form submissions.
