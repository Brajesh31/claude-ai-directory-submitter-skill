# Product Listing Copy Templates

Use these structures to prepare listing content. Replace every placeholder with a verified product fact. Do not publish claims that are not supported by the approved product brief.

## One-line pitch

[Product] helps [target user] achieve [specific outcome] with [distinct capability].

## Short description

[Product] is a [category] for [target audience]. It helps users [primary task] by [how it works]. Key capabilities include [verified feature 1], [verified feature 2], and [verified feature 3]. It is available as [deployment or pricing model].

## Full description

### The problem

Describe the specific workflow or obstacle the target user faces.

### How the product helps

Explain the product's main workflow in concrete terms. Avoid vague claims such as “revolutionary” or “best-in-class”.

### Key capabilities

- [Capability]: [user benefit].
- [Capability]: [user benefit].
- [Capability]: [user benefit].

### Who it is for

Describe the intended users and the situations where the product is useful.

### Availability

State the current platform support, pricing model, and meaningful limitations.

## Launch announcement

We built [Product] to help [audience] with [problem]. It provides [main capability] so users can [outcome]. It is available at [canonical URL]. We would value feedback from people working on [relevant use case].

## Final accuracy check

- Product name and URL are correct.
- Every feature is available now, not only planned.
- Pricing and availability are current.
- Comparisons are fair and verifiable.
- Metrics and testimonials have permission and evidence.
- Images and contact details are approved for public use.
